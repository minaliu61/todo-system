# 📝 Todo 作业待办管理系统

一个基于 Vue3 生态构建的轻量级作业任务管理应用，旨在帮助用户高效管理日常作业与任务进度。本项目为纯前端单页应用（SPA），无后端依赖，数据通过浏览器本地存储持久化。

## 🛠️ 技术栈
- **核心框架**：Vue 3 (Composition API)
- **构建工具**：Vite
- **状态管理**：Pinia + pinia-plugin-persistedstate (持久化)
- **路由管理**：Vue Router 4
- **UI 组件库**：Element Plus
- **语言**：JavaScript (ES6+)

## ✨ 核心功能
- **作业分类管理**：支持自定义添加、删除作业分类，灵活组织任务。
- **作业管理**：支持作业的新增、编辑和删除操作。
- **待办事项**：查看未完成的作业列表，并支持一键标记为“已完成”。
- **完成历史**：查看已完成的作业记录，支持撤销完成状态，实现数据双向流转。
- **数据持久化**：利用 Pinia 持久化插件，刷新页面不丢失数据。
